Palindrome String
Solved
Difficulty: BasicAccuracy: 51.21%Submissions: 524K+Points: 1
Given a string s, find if it is a palindrome. A string is considered a palindrome if it reads the same forwards and backwards.
Examples :
Input: s = "abba"
Output: true
Explanation: "abba" reads the same forwards and backwards, so it is a palindrome.
Input: s = "abc" 
Output: false
Explanation: "abc" does not read the same forwards and backwards, so it is not a palindrome.
Constraints:
1 ≤ s.size() ≤ 106
s contains: [a-z].

Expected Complexities
Time Complexity: O(n)
Auxiliary Space: O(1)

class Solution {
    public boolean isPalindrome(String s) {
        if (s == null) {
            return false;
        }
        // Kick off the recursion starting from the outer edges
        return checkPalindrome(s, 0, s.length() - 1);
    }
    // Helper method to perform the recursive checks
    private boolean checkPalindrome(String s, int low, int high) {
        // Base case: Pointers met or crossed, meaning all characters matched
        if (low >= high) {
            return true;
        }
        // If characters mismatch, it is not a palindrome
        if (s.charAt(low) != s.charAt(high)) {
            return false;
        }
        // Recursive case: Move pointers inward and check the rest
        return checkPalindrome(s, low + 1, high - 1);
    }
}
